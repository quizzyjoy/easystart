## 目录约定

```
教程/
├── README.md          # 本索引
└── <专题>/             # 一个专题一个目录（中文，如「主题」「列表」「动效」）
    ├── <专题>.md       # 单篇教程正文（与目录同名，整合为一篇，不拆多文件）
    └── 图片/           # 该篇引用的截图，随仓入库
```

新增教程时按上面的结构落盘，保持各篇风格一致：

1. **一篇一个文件**：教程整合成单篇，两级目录放在正文开头，用显式锚点（`<a id="chNN"></a>`）保证跨平台跳转稳定。
2. **截图放同目录 `图片/`**：不要引用被 `.gitignore` 忽略的目录（如 `plan/`），否则 clone 后图全裂；正文用相对路径 `图片/xxx.png`。
3. **每条结论带证据**：真机截图文件名，或可复现的命令。
4. **不臆造 API**：签名必须能在本仓源码或本机 SDK `d.ts` 中查到；查不到就标「需复核」，并列进文末清单。
5. **版本锚定**：教程开头写清对应 versionCode 区间，后续大改在该章末补「版本注记」。
