第三方 SDK 清单（占位模板）
============================

本文件为应用集成的第三方 SDK / 组件清单占位，fork 按实际依赖替换。

上架合规提示（AGC / 应用市场审核口径）：
- 隐私政策与本清单需列明应用集成的第三方 SDK 及其收集、使用个人信息的情况；
- 新增第三方依赖时，同步更新本清单与隐私政策对应章节。

模板自身内置（无第三方个人信息收集）：
- HarmonyOS SDK（@kit.*）：系统 API，华为官方提供；
- HDS UIDesignKit（@kit.UIDesignKit）：官方设计组件库；
- 模板三库（Foundation / Platform / VitalUI）：随模板源码分发，本地运行。

fork 接入第三方 SDK 后按以下格式逐行追加：
- SDK 名称 ｜ 提供方 ｜ 用途 ｜ 收集的信息 ｜ 官网 / 隐私政策链接
