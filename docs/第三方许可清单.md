# 第三方许可清单

## 说明

- 版本以 `hm_easystart/VersionFile.json5` 为准，本表仅记录用途与许可。
- 引用方式见 `教程/依赖/依赖.md`（本工程使用 `parameterFile` 参数化依赖，不能直接 `ohpm install <包名>`）。
- 含原生 `.so` 的依赖需在目标端真机验证，不能只看构建结果。
