# 权威参考与开源项目盘点

> **口径声明（2026-10-15 盘点；2026-10-16 升版刷新）**
> - **盘点范围**：本仓 `docs/`（含 `design/`）与 `hm_easystart/`（README、源码头注与注释、依赖清单）中参考、借鉴、依据过的权威文档、官方文档、示例代码与开源项目。时点：hm_easystart v3.29 / versionCode 1000017。
> - **链接口径**：外部链接仅收录 2026-10-15 经 webfetch 逐条验证可达且内容匹配的 URL；未能验证的条目**只登记名称 + 标识 + 建议检索方式**（集中见附录），绝不放置未经验证的链接。
> - **华为官方文档说明**：官方文档站为 JS 单页应用，任意路径（含不存在的）均返回同一「文档中心」外壳页，无法从仓外逐条验证 URL 真伪。因此华为官方文档条目一律以「文档标识 + MCP 解析的官方路径（形如 `alliance/document/cn/...` 或文档 slug）+ 检索方式」登记，不放完整 URL。检索工具：HarmonyOS Developer Knowledge MCP（`searchDocuments` 按标识/主题词检索）或官方文档站站内搜索。**标识为准、链接为便。**
> - **维护约定**：新增引用随模板轮次补登本表；链接失效时按标识经 MCP 重新检索。**2026-10-16 升版**：随 v3.29 轮补登选择器弹窗族 / PhotoViewPicker / 安全控件条目（TODO-020），既有链接维持 2026-10-15 验证口径。
